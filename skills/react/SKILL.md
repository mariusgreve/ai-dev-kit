# React

- Inspect the project's React version, routing, data-fetching and component conventions.
- Keep state as local as practical; derive values instead of synchronizing duplicate state.
- Use effects only to synchronize with external systems, with correct cleanup and dependencies.
- Preserve semantic HTML, keyboard access, focus behavior and accessible names.
- Test observable user behavior rather than component internals.
- Run lint, type checking and tests through the project verification entrypoint.
